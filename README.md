# Public APIs Collection

A curated directory of public APIs, organized by category and access model. Before integrating an API, check its official documentation and terms: quotas, pricing, authentication requirements, and permitted uses can change.

## Free and free-tier APIs

| API | Category | Access | Details |
| --- | --- | --- | --- |
| [Open-Meteo](https://open-meteo.com/) | Weather | No key; free for non-commercial use | [Weather APIs](weather-apis.md) |
| [Frankfurter](https://www.frankfurter.app/) | Finance | No key; free and open source | [Finance APIs](finance-apis.md) |
| [PokéAPI](https://pokeapi.co/) | Games | No key; free, follow fair use | [Entertainment APIs](entertainment-apis.md) |
| [TheDogAPI](https://thedogapi.com/) | Images | Key; free hobby/learning plan | [Image APIs](image-apis.md) |
| [CoinGecko Demo](https://www.coingecko.com/en/api) | Crypto | Demo key; $0 plan | [Finance APIs](finance-apis.md) |
| [ExchangeRate-API Open Access](https://www.exchangerate-api.com/docs/free) | Finance | No key; attribution required | [Finance APIs](finance-apis.md) |

## Paid and commercial APIs

| API | Category | Access / pricing model | Details |
| --- | --- | --- | --- |
| [OpenAI API](https://platform.openai.com/docs/pricing) | AI | Usage-based; model and modality dependent | [AI APIs](ai-apis.md) |
| [Google Maps Platform](https://developers.google.com/maps/billing-and-pricing/pricing) | Maps and location | Pay-as-you-go by SKU and billable events | [Maps and Location APIs](maps-location-apis.md) |
| [NewsAPI](https://newsapi.org/pricing) | News | Developer plan for development; paid plans for production | [News APIs](news-apis.md) |
| [Twilio](https://www.twilio.com/en-us/sms/pricing) | Communications | Pay-as-you-go; varies by product and destination | [Communication APIs](communication-apis.md) |
| [CoinGecko Pro](https://www.coingecko.com/en/api/pricing) | Crypto | Subscription tiers | [Finance APIs](finance-apis.md) |
| [WeatherAPI.com](https://www.weatherapi.com/pricing.aspx) | Weather | Free and paid subscription tiers | [Weather APIs](weather-apis.md) |

CoinGecko is listed in both access groups for its separate Demo and Pro plans. WeatherAPI.com also has a free tier, while its paid tiers are highlighted here as a commercial option. Pricing and usage limits are snapshots, not guarantees; consult each provider's official page before choosing a plan.
