# AI APIs

## OpenAI API

- **Type:** AI models for chat, summarization, classification, content generation, and other tasks
- **Authentication:** API key
- **Pricing:** Usage-based and varies by model and modality; token-based pricing applies to many text models.
- **API documentation:** [OpenAI platform docs](https://platform.openai.com/docs/)
- **Pricing:** [OpenAI API pricing](https://platform.openai.com/docs/pricing)

API usage is billed separately from ChatGPT subscriptions. Check model-specific rates and usage terms before estimating costs.
