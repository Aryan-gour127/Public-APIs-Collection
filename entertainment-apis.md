# Entertainment and Games APIs

## PokéAPI

- **Type:** Pokémon game data
- **Authentication:** None
- **Access:** Free and open; follow the project's fair-use policy.
- **API:** [pokeapi.co/api/v2](https://pokeapi.co/api/v2/)
- **Documentation and policy:** [PokéAPI](https://pokeapi.co/)

## Bucketlist Dream of the Day

- **Type:** One daily experience with an image and source URL
- **Authentication:** None
- **Access:** Free JSON endpoint; provider usage terms apply. No numerical quota or uptime guarantee is asserted.
- **Defaults:** Dutch language and Netherlands scope; the specification documents optional language, scope and theme parameters.
- **Documentation:** [OpenAPI specification](https://bucketlist.nl/brand/droom-van-de-dag.openapi.json)
