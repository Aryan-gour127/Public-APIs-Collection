# Free and Free-Tier APIs

The entries below have a no-cost access option. A free plan may have usage caps, attribution requirements, non-commercial restrictions, or development-only terms; check the provider's terms before use.

| API | Category | Authentication | Free access |
| --- | --- | --- | --- |
| [Open-Meteo](https://open-meteo.com/) | Weather | None | Free for non-commercial use; up to 10,000 calls/day. Attribution is required under the data licence. |
| [Frankfurter](https://www.frankfurter.app/) | Finance | None | Free and open source; daily exchange rates. |
| [PokéAPI](https://pokeapi.co/) | Games | None | Free and open; observe the fair-use policy. |
| [TheDogAPI](https://thedogapi.com/) | Images | API key | Free hobby/learning plan; quotas and features depend on the plan. |
| [CoinGecko Demo](https://www.coingecko.com/en/api) | Crypto | Demo API key | $0 Demo plan; published request limits apply. |
| [ExchangeRate-API Open Access](https://www.exchangerate-api.com/docs/free) | Finance | None | Open endpoint, daily updates, rate-limited; attribution required. |

Some providers also offer paid tiers. See the relevant category pages for more details.
