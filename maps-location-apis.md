# Maps and Location APIs

## Google Maps Platform

- **Type:** Maps, Places, geocoding, routes, and distance calculations
- **Authentication:** API key with a billing account
- **Pricing:** Pay-as-you-go by SKU and billable event. Global pricing currently includes a 10,000 free-usage cap for many core SKUs; caps differ by SKU, and regional pricing (including India) may differ.
- **Documentation:** [Google Maps Platform docs](https://developers.google.com/maps/documentation)
- **Pricing and billing:** [Global pricing](https://developers.google.com/maps/billing-and-pricing/pricing) · [India pricing](https://developers.google.com/maps/billing-and-pricing/pricing-india)

Enable only the APIs you need, restrict API keys, and review the applicable regional price list before deployment.
